CODE COMPILER — Saved static front-end copy

What this package contains
- index.html and the local JavaScript/CSS files saved from the original CODE COMPILER page.
- Browser-saved JavaScript filenames have been normalized for static hosting.

Important limitations
- This is a copy of the browser-facing page, NOT the original server-side project or a verified full source repository.
- The saved version uses a precompiled contract object for its Compile action; it does not include a complete Solidity compiler binary/source package for compiling arbitrary contracts.
- Wallet connection, blockchain RPC access, WalletConnect and other external services may still depend on third parties and may behave differently after hosting.
- Do not connect a wallet holding funds, reveal a seed phrase/private key, or sign a transaction until you have independently verified the app and its contract behavior.

GitHub Pages publishing (when ready)
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root: index.html, assets/, and this README.txt.
3. In the repository, open Settings > Pages and choose Deploy from a branch, branch main, folder /(root), then Save.
4. Open the URL GitHub Pages displays. Test the interface without connecting a wallet or signing transactions.

This package has been arranged for static hosting, but full functionality is not guaranteed.
